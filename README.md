# 🇲🇾 Dashboard Pemantauan Siasatan Kes Disyaki Measles & Rubella – Malaysia

Aplikasi web berasaskan pelayar untuk menganalisis dan memantau siasatan kes disyaki Measles dan Rubella di Malaysia berdasarkan data ekspot WHO dari **Sistem Maklumat Siasatan Measles (SM2)**.

* **100% Pemprosesan Tempatan:** Semua bacaan data fail Excel/CSV dan pengiraan indikator dijalankan secara lokal di dalam pelayar web pengguna (menggunakan SheetJS & Chart.js).

## Cara Penggunaan
1. Muat turun fail ekspot siasatan kes dari **SM2 (WHO Export .xlsx / .csv)**.
2. Buka pautan dashboard pada pelayar web (Google Chrome / Microsoft Edge disyorkan).
3. Muat naik fail pada kotak **Upload File SM2**.
4. Pilih **Tahun**, julat **Minggu Epidemiologi (ME)**, **Negeri**, **Daerah**, serta masukkan anggaran **Populasi**.
5. Klik **Apply Filter** untuk melihat analisis.
